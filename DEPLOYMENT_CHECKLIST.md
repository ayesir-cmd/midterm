# Deployment checklist

- [ ] Supabase project and pooler/direct mode selected
- [ ] Runtime role uses least privileges
- [ ] Migration role is separate
- [ ] TLS/CA configured
- [ ] Render secrets set
- [ ] Production admin bootstrap variables set
- [ ] Migrations applied
- [ ] Demo seeding left disabled
- [ ] `/health` passes
- [ ] HTTPS and secure cookies pass
- [ ] Login and forced password change pass
- [ ] CRUD, reports, PWA, and mobile layout checked
